One-time setup

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories, then choose your site repository.
  3. Permissions → Repository permissions → Contents: Read and write. Generate the token.

Your token is stored only in this browser. Nothing is sent anywhere except GitHub.

How publishing works

  1. Create or edit an entry, then press Publish. The change is saved to GitHub as a commit.
  2. GitHub Actions rebuilds your site automatically. This takes 1–2 minutes.
  3. Entries marked Draft stay hidden from the site, but remain in your repository.
